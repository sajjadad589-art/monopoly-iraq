# مونوبولي العراق – Prototype V1

نسخة ويب عربية قابلة للعب محلياً من 2 إلى 6 لاعبين، بتصميم رقعة عراقية وترتيب 40 خانة على بنية لعبة العقارات الكلاسيكية.

## التشغيل
شغّل المشروع من خادم ويب ثابت أو GitHub Pages. بسبب تقسيم محرك اللعبة إلى أجزاء، فتح `index.html` مباشرة بصيغة `file://` قد لا يعمل في بعض المتصفحات.

## ما هو منفذ حالياً
- 2–6 لاعبين محلياً على نفس الجهاز.
- رصيد ابتدائي 1,500 د.ع.
- مكافأة 200 د.ع عند المرور بنقطة البداية.
- مواقع الزوايا: البداية / السجن / الاستراحة / اذهب إلى السجن.
- شراء العقارات والمحطات والخدمات.
- الإيجار، المجموعات اللونية، ومضاعفة إيجار العقار غير المبني عند امتلاك المجموعة.
- بناء متوازن، 32 بيت و12 فندق في البنك.
- الرهن وفك الرهن +10%.
- المزاد عند عدم شراء العقار.
- فرصة وصندوق الحظ مع بطاقات حركة/دفع/قبض/سجن/خروج من السجن.
- الدبل ورمية إضافية، وثلاث دبلات = سجن.
- السجن: دبل أو 50 د.ع أو بطاقة خروج، وإجبار الدفع بعد المحاولة الثالثة.
- الاستراحة بدون jackpot.
- التداول بين اللاعبين.
- الإفلاس ونهاية اللعبة.
- الكاميرا تدور بحسب جهة اللاعب الحالي على الرقعة.

## التصميم
النسخة الحالية تستخدم منظور CSS ثلاثي الأبعاد كبروتوتايب. المرحلة التالية هي ترقية العرض إلى 3D فعلي باستخدام Three.js مع مجسمات الرقعة والنرد وقطع اللاعبين والمباني.
